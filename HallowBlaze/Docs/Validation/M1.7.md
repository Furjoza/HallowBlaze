# M1.7 — lifecycle runu

## Decyzja O-006

Właściciel rozstrzygnął 2026-09-09, że `Exit to Menu` zachowuje poprawny run save dla `Continue`. Trwałe porzucenie jest osobną akcją i nie usuwa profilu.

## Macierz przejść

| Stan wejściowy | Akcja | Stan sesji | Stan na dysku | Profil |
| --- | --- | --- | --- | --- |
| brak runu | `New Run` | aktywny świeży run | zapis aktywnego runu | zachowany |
| poprawny aktywny save | `Continue` | zapisany run dołączony | bez zmiany | zachowany |
| brak/uszkodzony/terminalny save | `Continue` | brak aktywnego runu | bez nadpisania | zachowany |
| aktywny run | granica planszy | aktywny run | atomowy zapis bieżącej granicy | zachowany |
| aktywny run | `Exit to Menu` | run odłączony | aktywny save zachowany | zachowany |
| aktywny run | trwałe porzucenie | run odłączony | current i backup runu usunięte | zachowany |
| aktywny run | `Dead` / `Won` | run zakończony i odłączony | run save usunięty po zapisie profilu | podsumowanie zapisane raz |

Przejścia zabronione: `Continue` dla terminalnego lub już podsumowanego runu; checkpoint bez aktywnego runu; zmiana wyniku już zakończonego runu. Błąd zapisu przy `Exit to Menu` pozostawia run dołączony i nie ładuje menu. Błąd persistence podczas finalizacji może być ponowiony bez duplikacji podsumowania.

## Punkty autosave

- utworzenie nowego runu, przed wejściem w rozgrywkę;
- po `AdvanceDay`, przed inicjalizacją każdej planszy;
- bezpośrednio przed `Exit to Menu`;
- profil przy `Dead` lub `Won`, przed usunięciem current i backup runu.

Mid-board snapshot pozostaje poza zakresem. Crash odtwarza ostatnią zatwierdzoną granicę planszy.
