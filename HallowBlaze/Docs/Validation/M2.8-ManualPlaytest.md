# M2.8 Atlas Persistence Manual Playtest Script

## Overview
This script provides step-by-step instructions for manually testing atlas persistence across game runs.

## Prerequisites
1. Unity Editor 6000.3.21f1
2. HallowBlaze project opened
3. Pipeline package installed

## Test Procedure

### Step 1: Prepare Test Environment
1. Open Unity Editor with HallowBlaze project
2. Wait for Pipeline server to initialize
3. Ensure no previous profile exists (or create a new one)

### Step 2: Run First Game Session
1. Start a new game session
2. Navigate to the atlas screen
3. Explore and discover new locations:
   - Discover "forest.west-grove" node; it should be marked Rumored
   - Discover "road.old-road-west-grove" edge
4. Close the atlas screen
5. Complete the game session (or save and exit)

### Step 3: Run Second Game Session
1. Start a new game session (this should load the profile from disk)
2. Navigate to the atlas screen
3. Verify that discoveries from the first session are visible:
   - "forest.west-grove" should be marked as Rumored
   - "road.old-road-west-grove" should be marked as Sighted
4. Close the atlas screen

### Step 4: Verify Persistence
The test is successful if:
- Discoveries from the first run are visible in the second run
- No manual rediscovery is needed
- Atlas shows consistent state across runs

## Alternative: Using Unity Test Runner

If you prefer to use the Unity Test Runner:

1. Open Unity Editor
2. Go to Window > General > Test Runner
3. Select "PlayMode" platform
4. Filter for "M28AtlasPersistenceTests"
5. Click "Run" button

## Expected Results

**Success**: All discoveries from the first run persist into the second run
**Failure**: Discoveries are not visible in the second run

## Troubleshooting

### Issue: Unity Editor not responding
- Restart Unity Editor
- Check for compilation errors
- Ensure Pipeline package is installed

### Issue: Discoveries not persisting
- Verify profile directory is writable
- Check that ProfileState is properly initialized
- Ensure RunState loads ProfileState correctly

### Issue: Test not found
- Reimport the test project
- Check that test file is in correct location
- Verify test is in PlayMode test project
